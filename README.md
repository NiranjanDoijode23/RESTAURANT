# 🍽️ Niru's Resto — Restaurant Website

A simple restaurant landing page built with **HTML & CSS**, created to practice CSS Grid and layout fundamentals.

---

## 📌 About

This is a static front-end practice project for a fictional restaurant called **Niru's Resto**. It covers common real-world layout patterns using modern CSS techniques.

---

## 🧱 Sections

- **Navbar** — Logo and brand name
- **Hero Section** — Promotional banner with a CTA button
- **Feature Cards** — Highlights fast delivery, fresh food, and discount vouchers
- **Menu Grid** — Food items displayed using CSS Grid
- **Footer** — Navigation links, support links, and email input

---

## 🛠️ Built With

- HTML5
- CSS3 (Grid, Flexbox)

---

## 🎯 Learning Goals

- CSS Grid layout (menu section with multi-item grid)
- Flexbox for navbar and card alignment
- Basic page structure and sectioning
- Responsive-friendly HTML structure
